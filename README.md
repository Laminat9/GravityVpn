## 🚀 О проекте

**Gravity** — это настольный клиент для Windows, разработанный в сдержанном монохромном стиле без кричащих градиентов и неона. Приложение работает «из коробки»: достаточно вставить ссылку на подписку формата Clash YAML, Base64, Shadowsocks, VMess, VLESS или Trojan, нажать «Подключиться», и весь сетевой трафик пойдёт через защищённый туннель.

### Ключевые возможности:
- **Открытое ядро Mihomo Meta v1.19.32 (64-bit)**: проверенное высокопроизводительное ядро с поддержкой современных протоколов (Shadowsocks, VMess, VLESS, Trojan, Hysteria2 и др.).
- **Доверенный Device ID (UUID v4)**: генерация стабильного идентификатора устройства и передача в заголовках `User-Agent` и `X-Hwid`, благодаря чему серверы подписок принимают Gravity как доверенный клиент.
- **Интеллектуальная фильтрация служебных узлов**: автоматическое отсечение внутренних заглушек маршрутизации (`PASS`, `PASS-RULE`, `REJECT-DROP`, loopback-сокетов) — в списке отображаются только реальные серверы.
- **Управление системным прокси Windows**: автоматическое включение/выключение через реестр Windows (`Internet Settings`) с немедленным применением через `wininet.dll`.
- **Безопасное завершение**: гарантированный сброс системного прокси при выходе или закрытии окна — интернет пользователя никогда не останется заблокированным.
- **REST API + WebSocket**: мониторинг скорости входящего и исходящего трафика в реальном времени через `ws://127.0.0.1:9090/traffic`.
- **Интерактивный список узлов (Серверы)**: замер задержки в миллисекундах по кнопке («Проверить пинг»), поиск по названию/протоколу и ручной выбор активного узла.
- **Логи ядра в реальном времени**: встроенный терминал с фильтрацией (Info, Warn, Error), поиском по строке и копированием в буфер.
- **Сворачивание в системный трей**: фоновая работа без лишних окон, быстрое управление через контекстное меню трея.

## 🎨 Дизайн и визуальная система

Интерфейс построен по принципам Anti-Slop дизайна с фиксированной шкалой токенов:
- **Глубинный фон окна**: `#0C0D0E`
- **Панели и контейнеры**: `#131417` и `#18191D`
- **Активные плашки и переключатели**: `#1F2026` и `#272930`
- **Разделители и границы**: `rgba(255, 255, 255, 0.05)` ... `0.16`
- **Основной текст и акценты**: `#EDEDED` (контрастный матовый серебряный/белый)
- **Второстепенный текст**: `#9DA1AA`
- **Приглушённый текст и метки**: `#5F636E`
- **Скругления (Радиусы)**: строгая шкала — `7px` (бейджи), `10px` (кнопки, поля, карточки), `14px` (контейнеры, терминал).
- **Иконки**: линейные SVG единой толщины (`strokeWidth = 1.8px`), без эмодзи.

## 🛠️ Установка и запуск

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/username/gravity-vpn.git
cd gravity-vpn
npm install
```

### 2. Загрузка ядра Mihomo
Для работы приложения требуется бинарник `mihomo.exe` в папке `core/`. Загрузите его автоматически:
```bash
npm run download:core
```
*Скрипт автоматически скачает совместимую 64-битную сборку с официального репозитория MetaCubeX и поместит её в `core/mihomo.exe`.*

### 3. Запуск в режиме разработки
```bash
npm run dev
```
Команда скомпилирует Electron-скрипты, запустит Vite dev-сервер и откроет окно приложения с поддержкой горячей перезагрузки (HMR).

## 📦 Сборка дистрибутива в `.exe`

Для сборки готового дистрибутива под Windows:

```bash
# Сборка портативной версии (Portable .exe)
npm run build:portable

# Сборка стандартного NSIS-установщика (.exe)
npm run build:nsis

# Полная сборка обоих форматов
npm run build
```

Готовые файлы появятся в директории `release/`:
- **`Gravity-Portable-1.0.0.exe`** (~90 MB) — запускается без установки из любой папки.
- **`Gravity Setup 1.0.0.exe`** — установщик с возможностью выбора пути и добавления ярлыков.
